# 우리 반 마피아 v2.0

초등학생 교실용 실시간 마피아 웹앱입니다. 최대 30명이 QR 코드로 입장할 수 있고, 교사가 역할 수와 라운드 시간을 정해 진행합니다.

## v2.0에서 달라진 점

- 게임 시작 직후 **15초 동안만 역할 공개**. 이후 학생 화면에서 역할 카드는 완전히 사라집니다.
- 마피아는 역할 공개 15초 동안 **다른 마피아 닉네임도 함께 확인**합니다.
- 투표 종료 후 **10초짜리 투표 결과 전체화면**을 모든 참가자에게 표시합니다.
- 표를 받은 학생과 각 득표수가 내림차순으로 표시됩니다.
- 화면 단계가 바뀔 때, 그리고 학생이 투표를 제출할 때 **짧은 띵동 효과음**이 납니다.
- 마피아/시민/경찰/의사 **자체 제작 SVG 캐릭터 이미지**를 역할 공개 화면에 표시합니다.
- 학생에게는 공개 시간이 지난 뒤 역할 정보가 화면뿐 아니라 일반 상태 데이터에서도 숨겨지도록 보강했습니다.
- 경찰의 조사 결과는 밤이 끝난 뒤 **다음 낮에 본인에게만** 표시됩니다.

## 기본 기능

- 교사용 방 생성 / 6자리 방 코드
- QR 코드 자동 생성
- 학생 닉네임 입장, 최대 30명
- 실시간 Socket.IO 연결
- 역할 수 지정: 마피아 / 시민 / 경찰 / 의사
- 무작위 역할 배정
- 낮 공개 채팅
- 서버 기준 타이머
- 역할 공개 → 낮 → 투표 → 투표 결과 → 밤 → 다음 라운드 자동 진행
- 생존자 투표 및 최다득표자 탈락 (동률이면 탈락 없음)
- 경찰: 밤마다 한 명 조사, 결과는 다음 낮 본인에게만 공개
- 마피아: 밤마다 시민 팀 한 명 공격
- 의사: 밤마다 한 명 보호(본인 보호 가능)
- 마피아 다수일 때 공격 대상은 마피아들의 다수결로 결정
- 교사는 모든 역할/상태/진행기록 확인 가능
- 교사가 낮/투표/투표결과/밤을 타이머 전에 마감 가능
- 교사가 채팅 전체 삭제 가능
- 새로고침 후 학생 재접속 지원(브라우저 로컬 토큰)

## 고정 시간

- 역할 공개: 15초
- 투표 결과 공개: 10초

`server.js` 상단의 아래 값을 바꾸면 수정할 수 있습니다.

```js
const ROLE_REVEAL_SECONDS = 15;
const VOTE_RESULT_SECONDS = 10;
```

## 승리 조건

1. 살아 있는 마피아가 0명이면 시민 팀 승리.
2. 요청한 규칙에 따라 살아 있는 마피아 수가 살아 있는 **시민 팀(시민+경찰+의사)** 수의 2배 이상이면 마피아 승리.

> 일반적인 마피아 게임의 승리 조건과 다릅니다. 현재는 요청한 `마피아 >= 시민팀 × 2` 규칙을 유지합니다.

## Render에서 기존 버전을 v2.0으로 업그레이드하는 가장 쉬운 방법

1. 새 ZIP을 다운로드하고 Windows에서 압축을 풉니다.
2. 압축을 푼 `mafia-classroom` 폴더 **안으로 들어갑니다**.
3. GitHub에서 기존 `mafia` 저장소를 엽니다.
4. `Add file` → `Upload files`를 누릅니다.
5. 압축을 푼 폴더 안의 **내용 전체**를 GitHub 업로드 화면으로 끌어 놓습니다. `mafia-classroom` 폴더 자체를 한 단계 더 올리지 마세요.
6. 기존 파일과 이름이 같은 파일은 변경 파일로 표시되고, `public/assets`의 캐릭터 SVG 4개는 새 파일로 표시됩니다.
7. 아래의 `Commit changes` 버튼을 누릅니다. 메시지는 예를 들어 `Upgrade classroom mafia to v2`라고 입력하면 됩니다.
8. Render가 Auto-Deploy 상태라면 잠시 뒤 자동으로 재배포됩니다.
9. 자동 배포가 시작되지 않으면 Render의 기존 `mafia` Web Service에서 `Manual Deploy` → `Deploy latest commit`을 누릅니다.
10. 배포가 `Live`가 된 뒤 기존 onrender.com 주소를 새로고침합니다. 웹 주소는 그대로 유지됩니다.

## 캐시 때문에 옛 화면이 보일 때

배포 성공 뒤에도 옛 화면이 보이면 브라우저에서 강력 새로고침을 해 보세요.

- Windows Chrome/Edge: `Ctrl + F5`
- 태블릿: 브라우저 탭을 완전히 닫았다가 다시 열기


## 로컬 실행

Node.js 18 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 교실 사용 팁

- 역할 공개 15초에는 학생들에게 태블릿을 가슴 쪽으로 살짝 기울여 자기 화면만 보게 안내하면 좋습니다.
- 효과음은 브라우저 보안 정책 때문에 학생이 입장 버튼 등을 한 번 누른 뒤부터 정상적으로 재생됩니다.
- Render 무료 서버는 한동안 사용하지 않으면 잠들 수 있으니 수업 시작 몇 분 전에 교사가 사이트를 먼저 열어 두는 것이 좋습니다.
- 서버가 재시작되면 진행 중인 방 상태는 사라지므로 매 수업마다 새 방을 만드는 방식이 안전합니다.

## v2.1 추가 기능
- 마피아의 밤 공격으로 실제 탈락한 학생에게만 개인 탈락 팝업과 짧은 탈락 효과음이 표시됩니다. 의사가 살린 경우에는 표시되지 않습니다.
- 게임 종료 시 교사와 모든 학생 화면에 승리 팀 팝업이 표시되고 짧은 승리 팡파르가 재생됩니다.
- 브라우저의 자동재생 제한 때문에 효과음은 해당 기기에서 한 번 이상 화면을 터치/클릭한 뒤 정상적으로 들립니다.

## v2.2 변경사항

- 학생 게임 화면의 작은 수업 안내/광고 자리(placeholder)를 완전히 삭제했습니다.
- 게임 기능, 역할 공개, 투표 결과, 효과음, 탈락 알림, 승리 팝업 기능은 그대로 유지됩니다.
