# 우리 반 마피아

초등학생 교실용 실시간 마피아 웹앱입니다. 최대 30명이 QR 코드로 입장할 수 있고, 교사가 역할 수와 라운드 시간을 정해 진행합니다.

## 포함 기능

- 교사용 방 생성 / 6자리 방 코드
- QR 코드 자동 생성
- 학생 닉네임 입장, 최대 30명
- 실시간 Socket.IO 연결
- 역할 수 지정: 마피아 / 시민 / 경찰 / 의사
- 무작위 역할 배정
- 낮 공개 채팅
- 서버 기준 타이머
- 낮 → 투표 → 밤 → 다음 라운드 자동 진행
- 생존자 투표 및 최다득표자 탈락 (동률이면 탈락 없음)
- 경찰: 밤마다 한 명 조사, 결과는 본인에게만 공개
- 마피아: 밤마다 시민 팀 한 명 공격
- 의사: 밤마다 한 명 보호(본인 보호 가능)
- 마피아 다수일 때 대상은 마피아들의 다수결로 결정
- 교사는 모든 역할/상태/진행기록 확인 가능
- 교사가 타이머 전에 다음 단계로 강제 진행 가능
- 교사가 채팅 전체 삭제 가능
- 새로고침 후 학생 재접속 지원(브라우저 로컬 토큰)

## 승리 조건

1. 살아 있는 마피아가 0명이면 시민 팀 승리.
2. 사용자가 요청한 규칙을 그대로 적용해, 살아 있는 마피아 수가 살아 있는 **시민 팀(시민+경찰+의사)** 수의 2배 이상이면 마피아 승리.

> 보통 마피아 게임은 `마피아 수 >= 시민 팀 수`일 때 마피아 승리로 정하지만, 이 버전은 요청하신 `2배 이상` 규칙을 적용했습니다. `server.js`의 `checkWin()`에서 쉽게 변경할 수 있습니다.

## 로컬 실행

Node.js 18 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`을 여세요.

### 같은 교실 와이파이에서 테스트

교사용 PC의 내부 IP가 예를 들어 `192.168.0.15`라면 학생들이 같은 와이파이에 연결된 상태에서

`http://192.168.0.15:3000`

으로 접속할 수 있습니다. 다만 QR에는 교사용 PC에서 연 주소가 그대로 들어가므로, 교사용 PC도 `localhost` 대신 내부 IP 주소로 페이지를 열어 방을 만드는 것이 좋습니다.

## 인터넷 배포

Render, Railway, Fly.io 같은 Node.js 호스팅에 올리면 외부 인터넷에서도 QR로 접속할 수 있습니다.

### Render 예시

1. 이 폴더를 GitHub 저장소에 올립니다.
2. Render에서 **New > Web Service**를 선택합니다.
3. 저장소를 연결합니다.
4. Build Command: `npm install`
5. Start Command: `npm start`
6. 배포된 HTTPS 주소로 접속해 방을 만듭니다.

## 교실 사용 시 참고

- 서버 메모리에 방 상태를 저장하므로 서버가 재시작되면 진행 중 게임은 사라집니다.
- 학생 개인정보는 입력하지 않고 닉네임만 사용하도록 안내하는 편이 안전합니다.
- 공개 채팅은 교사가 모두 지울 수 있습니다.
- 실제 수업에서는 닉네임 규칙, 채팅 예절, 탈락 학생의 관전 규칙을 먼저 안내하는 것을 권장합니다.
