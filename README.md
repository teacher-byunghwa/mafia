# 우리 반 마피아 v2.0

초등학생 교실용 실시간 마피아 웹앱입니다. 최대 30명이 QR 코드로 입장할 수 있고, 교사가 역할 수와 라운드 시간을 정해 진행합니다.

## v2.0에서 달라진 점

- 게임 시작 직후 **7초 동안만 역할 공개**. 이후 학생 화면에서 역할 카드는 완전히 사라집니다.
- 마피아는 역할 공개 7초 동안 **다른 마피아 닉네임도 함께 확인**합니다.
- 투표 종료 후 **10초짜리 투표 결과 전체화면**을 모든 참가자에게 표시합니다.
- 표를 받은 학생과 각 득표수가 내림차순으로 표시됩니다.
- 화면 단계가 바뀔 때, 그리고 학생이 투표를 제출할 때 **짧은 띵동 효과음**이 납니다.
- 마피아/시민/경찰/의사 **자체 제작 SVG 캐릭터 이미지**를 역할 공개 화면에 표시합니다.
- 학생에게는 공개 시간이 지난 뒤 역할 정보가 화면뿐 아니라 일반 상태 데이터에서도 숨겨지도록 보강했습니다.
- 경찰의 조사 결과는 밤이 끝난 뒤 **다음 낮에 본인에게만** 표시됩니다.

## 기본 기능

- 교사용 방 생성 / 6자리 방 코드
- QR 코드 자동 생성
- 학생 닉네임 입장, 최대 30명
- 실시간 Socket.IO 연결
- 역할 수 지정: 마피아 / 시민 / 경찰 / 의사
- 무작위 역할 배정
- 낮 공개 채팅
- 서버 기준 타이머
- 역할 공개 → 낮 → 투표 → 투표 결과 → 밤 → 다음 라운드 자동 진행
- 생존자 투표 및 최다득표자 탈락 (동률이면 탈락 없음)
- 경찰: 밤마다 한 명 조사, 결과는 다음 낮 본인에게만 공개
- 마피아: 밤마다 시민 팀 한 명 공격
- 의사: 밤마다 한 명 보호(본인 보호 가능)
- 마피아 다수일 때 공격 대상은 마피아들의 다수결로 결정
- 교사는 모든 역할/상태/진행기록 확인 가능
- 교사가 낮/투표/투표결과/밤을 타이머 전에 마감 가능
- 교사가 채팅 전체 삭제 가능
- 새로고침 후 학생 재접속 지원(브라우저 로컬 토큰)

## 고정 시간

- 역할 공개: 7초
- 투표 결과 공개: 10초

`server.js` 상단의 아래 값을 바꾸면 수정할 수 있습니다.

```js
const ROLE_REVEAL_SECONDS = 15;
const VOTE_RESULT_SECONDS = 10;
```

## 승리 조건

1. 살아 있는 마피아가 0명이면 시민 팀 승리.
2. 요청한 규칙에 따라 살아 있는 마피아 수가 살아 있는 **시민 팀(시민+경찰+의사)** 수의 2배 이상이면 마피아 승리.

> 일반적인 마피아 게임의 승리 조건과 다릅니다. 현재는 요청한 `마피아 >= 시민팀 × 2` 규칙을 유지합니다.

## Render에서 기존 버전을 v2.0으로 업그레이드하는 가장 쉬운 방법

1. 새 ZIP을 다운로드하고 Windows에서 압축을 풉니다.
2. 압축을 푼 `mafia-classroom` 폴더 **안으로 들어갑니다**.
3. GitHub에서 기존 `mafia` 저장소를 엽니다.
4. `Add file` → `Upload files`를 누릅니다.
5. 압축을 푼 폴더 안의 **내용 전체**를 GitHub 업로드 화면으로 끌어 놓습니다. `mafia-classroom` 폴더 자체를 한 단계 더 올리지 마세요.
6. 기존 파일과 이름이 같은 파일은 변경 파일로 표시되고, `public/assets`의 캐릭터 SVG 4개는 새 파일로 표시됩니다.
7. 아래의 `Commit changes` 버튼을 누릅니다. 메시지는 예를 들어 `Upgrade classroom mafia to v2`라고 입력하면 됩니다.
8. Render가 Auto-Deploy 상태라면 잠시 뒤 자동으로 재배포됩니다.
9. 자동 배포가 시작되지 않으면 Render의 기존 `mafia` Web Service에서 `Manual Deploy` → `Deploy latest commit`을 누릅니다.
10. 배포가 `Live`가 된 뒤 기존 onrender.com 주소를 새로고침합니다. 웹 주소는 그대로 유지됩니다.

배포 성공 뒤에도 옛 화면이 보이면 브라우저에서 강력 새로고침을 해 보세요.

- Windows Chrome/Edge: `Ctrl + F5`
- 태블릿: 브라우저 탭을 완전히 닫았다가 다시 열기


## 로컬 실행

Node.js 18 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 교실 사용 팁

- 역할 공개 7초에는 학생들에게 태블릿을 가슴 쪽으로 살짝 기울여 자기 화면만 보게 안내하면 좋습니다.
- 효과음은 브라우저 보안 정책 때문에 학생이 입장 버튼 등을 한 번 누른 뒤부터 정상적으로 재생됩니다.
- Render 무료 서버는 한동안 사용하지 않으면 잠들 수 있으니 수업 시작 몇 분 전에 교사가 사이트를 먼저 열어 두는 것이 좋습니다.
- 서버가 재시작되면 진행 중인 방 상태는 사라지므로 매 수업마다 새 방을 만드는 방식이 안전합니다.

## v2.1 추가 기능
- 마피아의 밤 공격으로 실제 탈락한 학생에게만 개인 탈락 팝업과 짧은 탈락 효과음이 표시됩니다. 의사가 살린 경우에는 표시되지 않습니다.
- 게임 종료 시 교사와 모든 학생 화면에 승리 팀 팝업이 표시되고 짧은 승리 팡파르가 재생됩니다.
- 브라우저의 자동재생 제한 때문에 효과음은 해당 기기에서 한 번 이상 화면을 터치/클릭한 뒤 정상적으로 들립니다.

## v2.2 변경사항

- 학생 게임 화면의 작은 수업 안내/광고 자리(placeholder)를 완전히 삭제했습니다.
- 게임 기능, 역할 공개, 투표 결과, 효과음, 탈락 알림, 승리 팝업 기능은 그대로 유지됩니다.

## v2.3 변경사항

- 마피아 승리 조건을 표준 규칙으로 수정했습니다.
- 살아 있는 마피아 수가 살아 있는 시민 팀(일반 시민 + 경찰 + 의사) 수와 같거나 많아지는 즉시 마피아가 승리합니다.
- 따라서 1:1, 2:2, 2:1 상황에서는 마피아가 승리합니다.
- 모든 마피아가 탈락하면 기존과 동일하게 시민 팀이 승리합니다.


## v2.4 변경사항

- 화면 상단에 `만든이: 김병화 선생님`을 작게 표시했습니다.
- 밤에는 살아 있는 마피아·시민·경찰·의사 모두에게 동일한 '한 명 선택' 화면이 표시됩니다.
- 일반 시민의 밤 선택은 실제 게임 결과에 아무런 영향을 주지 않습니다.
- 밤 타이머는 안내용입니다. 0초가 지나도 선택할 수 있으며, 살아 있는 전원이 한 명씩 선택해야만 다음 단계로 넘어갑니다.
- 마피아들의 선택 중 시민 팀(시민·경찰·의사)이 받은 표만 실제 공격표로 계산하며, 최다 득표자가 공격 대상이 됩니다.
- 공동 최다 득표가 있으면 공동 1위 중 한 명을 무작위로 선택합니다.
- 밤의 득표 수와 득표 내역은 학생에게 공개하지 않습니다.
- 밤에 실제 탈락자가 생기면 모든 화면에 탈락 학생의 닉네임과 역할(시민/경찰/의사 등)을 팝업으로 공개합니다.
- 의사가 살린 경우에는 모두에게 '아무도 탈락하지 않았습니다' 결과를 표시합니다.


## v2.5 변경사항

- 교사 화면에만 `밤 강제 진행` 버튼을 추가했습니다.
- 교사가 강제 진행을 누르면 아직 선택하지 않은 학생의 행동은 없는 것으로 처리하고, 그 시점까지 제출된 행동만 반영해 밤을 진행합니다.
- 강제 진행 전에는 현재 선택 완료 인원 수를 보여 주는 확인창이 한 번 뜹니다.
- 마피아가 실제로 공격하려던 학생을 의사가 정확히 보호한 경우, 모두에게 `마피아는 ○○ 학생을 공격하려 했지만 의사가 구했습니다`라고 공개합니다.
- 이때 의사가 누구인지는 공개하지 않습니다.
- 의사가 자기 자신을 보호했더라도 마피아가 다른 학생을 공격했다면, 그 의사의 보호 행동에 대해서는 아무 정보도 공개하지 않습니다.
- 즉, 의사의 행동은 '실제 마피아 공격을 막은 경우'에만 공개 결과에 나타납니다.


## v2.6 변경사항

- 게임 시작 직후 역할 공개 시간을 15초에서 **7초**로 줄였습니다.
- 7초가 지나면 학생 화면에서 자신의 역할과 마피아 동료 정보가 자동으로 숨겨집니다.


## v2.7 변경사항

- 게임 시작 직후 역할 공개 시간을 다시 **15초**로 되돌렸습니다.
- 마피아는 이 15초 동안 자신의 역할과 다른 마피아들의 닉네임을 함께 확인할 수 있습니다.
- 15초가 지나면 역할 정보와 마피아 동료 정보는 자동으로 숨겨집니다.


## v2.8 변경사항

- 최초 **15초 역할 공개**는 그대로 유지합니다.
- 마피아 학생은 게임 도중 자신의 닉네임을 약 **1.5초 길게 누르면** 마피아 팀원을 다시 확인할 수 있습니다.
- 표시 문구는 `마피아팀원: 철수, 민지` 형식입니다.
- 팀원 안내는 닉네임 바로 아래에 작게 나타나며 **3초 뒤 자동으로 사라집니다**.
- 별도 버튼, 효과음, 진동을 사용하지 않아 다른 학생이 눈치채기 어렵게 했습니다.
- 시민·경찰·의사가 닉네임을 길게 눌러도 아무것도 나타나지 않습니다.


## v2.9 변경사항

- 교사와 학생 기기의 타이머를 **Render 서버 시간 기준으로 동기화**하도록 변경했습니다.
- 접속 직후 서버와 여러 번 짧게 통신해 각 기기의 시계 차이와 네트워크 왕복 지연(RTT)을 보정합니다.
- 여러 표본 중 네트워크 지연이 가장 짧은 표본을 사용해 서버 시각과의 오차를 줄입니다.
- 게임 중에도 약 30초마다 서버 시각을 다시 동기화합니다.
- 카운트다운은 더 이상 각 태블릿/PC의 로컬 시계만 사용하지 않고 `서버 종료 시각 - 동기화된 서버 현재 시각`으로 계산합니다.
- 네트워크 상태에 따라 순간적으로 0~1초 정도의 표시 차이는 생길 수 있지만, 이전처럼 기기 시계 차이 때문에 몇 초씩 벌어지는 현상을 크게 줄였습니다.


## v3.0 변경사항

- 학생이 교사가 만든 QR 코드(`?room=방번호`)로 접속하면 **교사용 방 만들기 화면을 완전히 숨깁니다**.
- QR 학생 화면에는 `마피아 게임 간단 안내 + 학생 입장`만 표시됩니다.
- 학생은 방 번호를 수정할 필요가 없도록 QR의 방 번호가 자동 입력되고 읽기 전용으로 표시됩니다.
- 닉네임만 입력한 뒤 `입장하기`를 누르면 됩니다.
- 선생님이 기본 홈페이지 주소로 접속하면 기존과 동일하게 역할 수와 시간을 설정하는 `교사용 방 만들기` 화면이 표시됩니다.
- 학생 안내에는 15초 역할 확인, 낮 토론·투표, 밤 선택, 역할 비밀 유지 등 기본 규칙만 보여 줍니다.


## v3.1 변경사항

- 선생님이 기본 웹주소로 접속하면 **교사용 방 만들기 화면만** 표시됩니다.
- 기본 화면에서 학생 입장 카드와 학생 안내는 완전히 숨겼습니다.
- 학생이 선생님이 만든 QR코드(`?room=방번호`)로 접속한 경우에만 **마피아 게임 안내 + 학생 입장** 화면이 표시됩니다.
- 기존 게임 기능은 그대로 유지됩니다.


## v3.2 변경사항

- 기본화면의 큰 제목 `우리 반 마피아`는 그대로 유지했습니다.
- 제목 아래 설명 문구를 `QR로 입장하고, 닉네임으로 참여하는 최대 30인 실시간 마피아 게임`에서 **`친구들과 함께 하는 행복한 마피아 게임`**로 변경했습니다.
